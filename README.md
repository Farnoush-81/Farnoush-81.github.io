# Farnoosh Portfolio

پورتفولیوی شخصی فرنوش صفرزاده‌نیا

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## ساختار
- `index.html` — ساختار صفحه
- `style.css` — طراحی و responsive
- `script.js` — انیمیشن ورود، منوی موبایل و رفتارهای تعاملی
- `assets/farnoosh-portrait.png` — تصویر پروفایل

## شخصی‌سازی
برای اضافه کردن پروژه‌های واقعی، بخش `projects` در `index.html` را ویرایش کنید.
همچنین ایمیل نمونه `hello@farnoosh.dev` را با ایمیل واقعی خودتان جایگزین کنید.
